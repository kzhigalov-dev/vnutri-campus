# Внутри — студенческий навигатор СПбГУПТД

Практическое задание №4: интерактивная карта и живой интерфейс бронирования. Корпус на Вознесенском проспекте, 44–46, четвёртый этаж. Идея: найти пространство под свою задачу и забронировать отдельные места для самостоятельной работы.

## Запуск

Нужен обычный статический HTTP-сервер (ES-модули не открываются через `file://`):

```sh
python3 -m http.server 8000 --directory dist
```

Открыть `http://localhost:8000`. Сборка, npm, API-ключи, регистрация и серверная база не нужны. HTML, CSS, ванильный JavaScript; Three.js 0.180.0 и шрифты поставляются локально.

## Что работает

- Вечерняя интерактивная 3D-схема с освещёнными интерьерами, вращением, приближением и общим видом. Доступна плоская схема 2D; при отказе WebGL она включается автоматически.
- Восемь пространств, по восемь учебных мест: 64 места. Карта, карточки и список синхронизированы.
- Поиск по названию/номеру/оборудованию; фильтры типа, максимального тарифа и свободных мест. Скрытый фильтром выбор сбрасывается.
- Выбор даты, начала, 1–4 часов и нескольких свободных мест. Итог = тариф × часы × число мест. Проверяются пересечения интервалов, границы даты и времени; смежные брони допустимы.
- Одно подтверждение создаёт одну запись с номером. «Мои брони», восстановление после перезагрузки, отмена и подтверждаемый сброс демо.
- Сохранение в одном ключе `vnutri.campus.bookings.v1`, синхронизация вкладок, защита от повреждённых данных и отказа записи. При наличии Web Locks изменения вкладок сериализуются. Лимит — 250 записей с понятной ошибкой до сохранения; прошедшие дни скрываются.
- Адаптивная форма, клавиатурный выбор через кнопки, видимый фокус, подписи состояний и ошибки рядом с полями.
- Отдельный поисковый справочник 22 кабинетов с источниками и спорными сведениями; архивный поэтажный план с увеличением.

Даты — сегодня и следующие 14 дней по Москве; начало 09:00–20:00, конец не позднее 21:00. Каждый день примерные места 2 и 6 заняты с 12:00 до 15:00; в читальной зоне в этот интервал заняты все места.

## Достоверность и ограничения

**Учебное демо: бронирования сохраняются только в этом браузере**. Нет реального резерва, оплаты, авторизации или общего расписания. Бронь не предоставляет право доступа в аудиторию. Локальные данные разных устройств и доменов не синхронизируются. Без Web Locks повторная проверка данных сохраняется, но строгая атомарность между вкладками не гарантируется.

Назначение аудиторий 452, 459, 462, 466 и 484 и их отнесение к четвёртому этажу подтверждены [образовательной программой 2025 года](https://sutd.ru/sveden/oop/09.02.13-co.pdf). Зоны А, Б и В — предложения для пилота. По восемь мест в каждой зоне, все тарифы, занятость и расположение в 3D придуманы для демонстрации. Они не означают реальную вместимость или свободный доступ.

Архивный план 2012 года найден на PDF-странице 322 [экспертизы 2023 года](https://saintcapybaras.com/Home/GetStateExamination/11435?page=102). Фрагмент обрезан и тонально усилен для читаемости; полный лист сохранён отдельно без такой коррекции. Современная нумерация и изменения планировки не проверены. 3D-сцена — концепция, не точная реконструкция и не маршрут по зданию.

Полный перечень источников и статусы: [исследование](research/voznesensky-44-46/README.md), [данные](research/voznesensky-44-46/rooms-research.json). Университет уже описывал инициативу интерактивной карты и бронирования [в 2024 году](https://sutd.ru/novosti_i_obyavleniya/announces/24689/); проект не претендует на первенство этой идеи.

## Проверка

```sh
node --test tests/model.test.mjs
```

Нужен современный Node.js с ES-модулями и Web Crypto. В браузере: выбрать место → изменить время → проверить сумму → подтвердить → обновить страницу → открыть «Мои брони» → отменить → убедиться, что место свободно. Также проверить пустой выбор, неверную длительность, занятые места, пустой фильтр, 2D и мобильный экран. Подробности фактически выполненной проверки: [docs/verification.md](docs/verification.md).

## Нейросеть и промпты

Проект разработан совместно с OpenAI Codex. Ключевые запросы пользователя:

1. «Думаю вечерняя версия, но с внутренним освещением, чтобы была также детализация».
2. «А может сделать интерактивную карту прям по корпусам, с тем что есть интересного где какие кабинеты и так далее»; начать с Вознесенского, 44–46, четвёртого этажа.
3. «По заданию надо ещё сделать бронирование, предлагаю добавить возможность бронирования мест в кабинетах для самостоятельной работы и других подобных местах».

Исследование источников, код, тесты и визуальные проверки выполнены с помощью Codex. Three.js — MIT, лицензия в `dist/vendor/THREE-LICENSE.txt`; Manrope и Oswald — SIL OFL, лицензии в `dist/fonts/`. Университетские сведения и архивный документ сопровождаются ссылками на источники.

## Файлы и публикация

`dist/` — готовый сайт; `dist/js/model.js` — расчёт/занятость/хранение; `dist/js/app.js` — интерфейс; `dist/js/scene.js` — Three.js; `tests/` — доменные проверки. Для любого статического хостинга публикуется папка `dist` целиком.

Конфигурация Sites сохранена в `.openai/hosting.json`. Существующий доступ сайта сохранён приватным для владельца. Для сдачи преподавателю потребуется открыть доступ в настройках Sites или разместить `dist/` на публичном статическом хостинге.
