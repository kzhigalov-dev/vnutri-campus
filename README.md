# внутри. — навигатор СПбГУПТД

Вознесенский,44–46: вечернее здание → пять отдельных3D-планировок → отдельная страница бесплатной учебной брони. Интерфейс — HTML,CSS и ванильный JavaScript; Three.js и шрифты поставляются локально.

## Запуск

Нужны Node.js22.13+ и npm для полного режима с подготовленным сервером:

```sh
npm ci
npm run dev -- --port 4173 --hostname 127.0.0.1
```

Открыть http://127.0.0.1:4173/index.html. Без ключей доступен учебный режим: записи сохраняются только в этом браузере.

Для сдачи статической части задания без npm/сборки/сервера API:

```sh
python3 -m http.server 8000 --directory public
```

Открыть http://localhost:8000/index.html. Все модели, каталог, локальная бронь, образец письма и отмена работают; API недоступен и интерфейс прямо сообщает об учебном режиме.

## Что работает

- Полноэкранное вечернее здание, выбор этажей наведением/кнопками, компактное меню.
- Пять разных моделей по архивным планам: стены, лестничные участки, условная мебель и освещение; вращение, масштаб, перенос, вид сверху, наложение скана и исходный2D-чертёж. Подписаны подтверждённые лестничные участки.
- Отдельные страницы бронирования и справочника22 кабинетов. Поиск, тип пространства, фильтр свободных мест.
- Восемь пространств по восемь учебных мест. Дата — сегодня и14 дней вперёд по Москве, начало09–20,1–4 часа, конец до21. Бесплатно для любого количества мест.
- Проверка ошибок и пересечений, сохранение, восстановление после обновления, отмена и освобождение мест; синхронизация вкладок. Старые учебные записи с тарифами сохраняются с нулевой стоимостью.
- После учебной записи доступен образец письма с кнопкой отмены. Открытие ссылки только показывает бронь; отмена требует нажатия кнопки.
- Подготовленный сервер: Sites Vinext Worker,D1, уникальные слоты для защиты от двойной брони, записи владельца через ChatGPT identity, Resend, защищённая ссылка отмены. Успех сохранения и статус отправки письма разделены.

## Что ещё не подключено

Почтового домена и сервиса пока нет: **настоящие письма не отправляются**, серверное создание брони отключено. Сейчас работает явно обозначенная локальная демонстрация. Она не предоставляет права доступа в аудитории.

Для включения пилота позже: подтвердить домен отправителя в Resend и настроить через Sites runtime variables `RESEND_API_KEY`, `MAIL_FROM` (адрес), `SITE_URL` (HTTPS-адрес этого сайта), `BOOKING_TOKEN_SECRET` (случайный секрет минимум32 символа), затем `BOOKING_ENABLED=true`. Секреты не помещать в public/или hosting.json. `.env.example` содержит только имена. Подготовленный сервер использует почту вошедшего аккаунта, не произвольный адрес получателя. Включение настоящего доступа к помещениям требует согласования с университетом.

Миграция D1 находится в drizzle/. Sites применяет её при публикации. Для локальной базы после сборки:

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_tan_gambit.sql
```

## Достоверность

Назначения аудиторий452,459,462,466,484 подтверждены [программой2025года](https://sutd.ru/sveden/oop/09.02.13-co.pdf). Зоны А,Б,В — предложения. Восемь мест и свободный доступ — учебный сценарий. Примерная занятость:12–15 места2,6, а в читальной зоне все места. В серверном режиме этой демонстрационной занятости нет.

Геометрия перенесена с [архивных чертежей2012года](https://saintcapybaras.com/Home/GetStateExamination/11435?page=102), страницы319–323 экспертизы2023года. Современная нумерация к этим помещениям **не привязана**: номера и подсветка бронируемых комнат на модели не расставляются наугад. Стены отражают архив, не проверенное состояние2026года. Высоты, фасад, свет и мебель условные; не использовать для эвакуации.

[Дополнительный поиск актуальных схем](research/voznesensky-44-46/current-plan-search-2026-10-29.md) не дал читаемого плана с современной нумерацией. [Концепция модернизации университета](https://sutd.ru/novosti_i_obyavleniya/announces/24689/) уже включает навигацию и бронирование; работа развивает пользовательский сценарий, не претендует на первенство идеи.
